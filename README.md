# **Rapid Run - Horse Running Game**

This repository contains the **Rapid Run** Horse Running Game implemented in both **Python** and **Java**. The game simulates a horse race, allowing players to experience an interactive gaming experience.

## 📁 Repository Structure

The project is divided into two main directories:

- **Python/** - Contains the Python implementation of the game.
- **Java/** - Contains the Java implementation, including the GUI design.

## 🔹 Features

### Python Implementation
- Command-line based horse racing simulation.
- Uses basic data structures for race mechanics.
- Simple and lightweight.

### Java Implementation
- **Graphical User Interface (GUI)**
- Interactive horse selection and race tracking.

## 🛠 Technologies Used

- **Python** (for CLI-based game)
- **Java (Swing/JavaFX)** (for GUI-based game)
- **Object-Oriented Programming (OOP)**
- **File Handling** (for storing race details)
